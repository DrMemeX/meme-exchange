## 1. Пользователь

Пользователь — учётная запись участника площадки.
Поля профиля входят в описание пользователя.

### Поля

| Поле               | Описание                                                                                                                          | Пример                                           |
|--------------------|-----------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------|
| Идентификатор      | Уникален. Сохраняется при смене логина                                                                                            | 101                                              |
| Логин              | От 3 до 30 символов. Латинские буквы, цифры, дефис и нижнее подчёркивание. Уникален с учётом регистра                             | DrMemeX                                          |
| Электронная почта  | Обязательный адрес без пробелов. Уникален без учёта регистра среди неудалённых аккаунтов. После регистрации неизменяем            | drmemex@example.com                              |
| Пароль             | От 8 до 64 символов. Латинские буквы, цифры, дефис и нижнее подчёркивание. Регистр учитывается. В ответах системы не отображается | Meme_Pass-2026 — пример пользовательского пароля |
| Роль               | Пользователь, Администратор или Суперадминистратор. Назначается при создании аккаунта и не меняется                               | Пользователь                                     |
| Статус             | Активен, Заблокирован или Удалён                                                                                                  | Активен                                          |
| О себе             | Необязательный текст до 500 символов                                                                                              | Собираю мемы с Путиным                           |
| Дата регистрации   | Дата и время создания аккаунта                                                                                                    | 2026-11-20T16:32:00+03:00                        |
| Причина блокировки | Обязательна при блокировке. От 1 до 500 символов после удаления пробельных символов по краям                                      | Не указана, поскольку аккаунт активен            |

### Действия

- Посетитель — создать аккаунт с ролью «Пользователь»;
- Владелец аккаунта любой роли — войти в свой аккаунт;
- Владелец аккаунта любой роли — выйти из своего аккаунта;
- Владелец аккаунта любой роли — просмотреть свой профиль;
- Владелец аккаунта любой роли — изменить свой логин;
- Владелец аккаунта любой роли — изменить свой пароль;
- Владелец аккаунта любой роли — изменить или очистить текст «О себе»;
- Пользователь — просмотреть общий список активных пользователей и найти пользователя по логину;
- Пользователь — просмотреть публичный профиль другого активного пользователя;
- Пользователь или Администратор — удалить собственный активный аккаунт;
- Администратор — просмотреть список аккаунтов с ролью «Пользователь»;
- Администратор — заблокировать или разблокировать аккаунт с ролью «Пользователь»;
- Суперадминистратор — выполнять административные действия Администратора;
- Суперадминистратор — создать отдельный аккаунт с ролью «Администратор»;
- Суперадминистратор — просмотреть список администраторов;
- Суперадминистратор — заблокировать или разблокировать аккаунт с ролью «Администратор».

Аккаунт суперадминистратора существует с момента запуска площадки.
Его блокировка и удаление через функции площадки запрещены.

## 2. Мем

Мем — опубликованное изображение с уникальным названием и одним текущим владельцем. Пользователь, опубликовавший мем, становится
его первым владельцем. При покупке владелец меняется.

### Поля


| Поле                             | Описание                                                                                                                    | Пример                             |
|----------------------------------|-----------------------------------------------------------------------------------------------------------------------------|------------------------------------|
| Идентификатор                    | Уникален                                                                                                                    | 501                                |
| Название                         | От 1 до 100 символов после удаления пробелов по краям. Уникально без учёта регистра, включая названия заблокированных мемов | Кот Путина                         |
| Изображение                      | Один файл JPEG или PNG размером до 5 МБ                                                                                     | cat.png, 1 МБ                      |
| Текущий владелец                 | Аккаунт, которому принадлежит мем. Для аккаунта суперадминистратора отображается «Platform»                                 | DrMemeX                            |
| Дата публикации                  | Дата и время публикации. Сохраняется при смене владельца                                                                    | 2026-11-20T16:32:00+03:00          |
| Текущая оценка                   | Целое количество мемкоинов. Начальная оценка — 10 мемкоинов                                                                 | 24 мемкоина                        |
| Количество уникальных просмотров | Число засчитанных просмотров                                                                                                | 27                                 |
| Количество активных лайков       | Число поставленных лайков и не снятых лайков                                                                                | 4                                  |
| Состояние продажи                | Продаётся или Не продаётся                                                                                                  | Продаётся                          |
| Состояние модерации              | Доступен или Заблокирован                                                                                                   | Доступен                           |
| Причина блокировки               | Обязательна при блокировке. От 1 до 500 символов после удаления пробельных символов по краям                                | Не указана, поскольку мем доступен |

Название и изображение после публикации неизменяемы.

### Действия

- Пользователь — опубликовать мем (не более 5 мемов за скользящее окно продолжительностью 60 минут);
- Пользователь — просмотреть ленту мемов;
- Пользователь — найти мем по названию;
- Пользователь — открыть карточку доступного мема;
- Пользователь — просмотреть свою коллекцию;
- Пользователь — просмотреть коллекцию другого активного пользователя;
- Пользователь — купить чужой мем по действующему предложению;
- Администратор или Суперадминистратор — просмотреть мем для модерации, включая заблокированный;
- Администратор или Суперадминистратор — заблокировать мем с указанием причины;
- Администратор или Суперадминистратор — разблокировать мем.

## 3. Лайк

Лайк — положительная реакция конкретного пользователя на конкретный мем.
Один пользователь может иметь не более одного активного лайка на одном меме.

### Поля

| Поле         | Описание                           | Пример      |
|--------------|------------------------------------|-------------|
| Пользователь | Аккаунт, поставивший реакцию       | аккаунт 102 |
| Мем          | Мем, на который поставлена реакция | мем 501     |
| Состояние    | Активен или Неактивен              | Активен     |

### Действия

- Пользователь — поставить лайк чужому незаблокированному мему;
- Пользователь — снять свой лайк с незаблокированного мема.

## 4. Просмотр

Просмотр — факт засчитанного открытия карточки мема конкретным пользователем.
С одного аккаунта засчитывается не более одного просмотра одного мема за всё время.

### Поля

| Поле         | Описание                            | Пример                    |
|--------------|-------------------------------------|---------------------------|
| Пользователь | Аккаунт, которому засчитан просмотр | аккаунт 102               |
| Мем          | Просмотренный мем                   | мем 501                   |
| Дата и время | Момент, когда просмотр был засчитан | 2026-11-20T16:32:00+03:00 |

Просмотры владельца и административные просмотры при модерации не засчитываются.

## 5. Предложение о продаже

Предложение о продаже — выставление мема на продажу.
Для одного мема допускается только одно активное предложение.
При повторном выставлении создаётся новое предложение.

### Поля

| Поле             | Описание                                                                                                                               | Пример                    |
|------------------|----------------------------------------------------------------------------------------------------------------------------------------|---------------------------|
| Идентификатор    | Уникален. При повторном выставлении мема создаётся новое предложение                                                                   | 701                       |
| Мем              | Мем, выставленный на продажу                                                                                                           | мем 501                   |
| Продавец         | Аккаунт, которому принадлежал мем при создании предложения. Для суперадминистратора отображается «Platform»                            | аккаунт 101               |
| Состояние        | Активно или Неактивно                                                                                                                  | Неактивно                 |
| Цена             | Пока предложение активно, равна текущей оценке мема и меняется вместе с ней. После закрытия сохраняется последнее значение             | 24 мемкоина               |
| Дата создания    | Дата и время выставления мема на продажу                                                                                               | 2026-11-20T16:32:00+03:00 |
| Дата закрытия    | Дата и время закрытия. Для активного предложения не указана                                                                            | 2026-11-21T16:32:00+03:00 |
| Причина закрытия | Покупка, снятие с продажи владельцем, блокировка мема, блокировка или удаление аккаунта продавца. Для активного предложения не указана | Покупка                   |

### Действия

- Пользователь — создать предложение для своего незаблокированного мема;
- Пользователь — закрыть своё активное предложение, тем самым сняв мем с продажи;
- Пользователь — просмотреть действующее предложение в ленте или коллекции владельца.

## 6. Сделка

Сделка — факт завершённой покупки мема.

### Поля

| Поле                  | Описание                                                                | Пример                     |
|-----------------------|-------------------------------------------------------------------------|----------------------------|
| Идентификатор         | Уникален                                                                | 801                        |
| Предложение о продаже | Предложение, по которому состоялась покупка                             | предложение 701            |
| Мем                   | Купленный мем                                                           | мем 501                    |
| Продавец              | Аккаунт, продавший мем. Для суперадминистратора отображается «Platform» | аккаунт 101                |
| Покупатель            | Пользователь, купивший мем                                              | аккаунт 102                |
| Сумма                 | Положительное целое количество мемкоинов, зафиксированное при покупке   | 24 мемкоина                |
| Дата и время          | Момент завершения сделки                                                | 2026-11-21T16:32:00+03:00  |


### Действия

- Покупатель — просмотреть сделку в истории покупок;
- Продавец — просмотреть сделку в истории продаж.

## 7. Кошелёк

Кошелёк — счёт для учёта мемкоинов. Личный кошелёк принадлежит пользователю с ролью «Пользователь». Фонд площадки учитывается
как отдельный кошелёк, принадлежащий суперадмину.

### Поля

| Поле     | Описание                                                                                                      | Пример      |
|----------|---------------------------------------------------------------------------------------------------------------|-------------|
| Владелец | Аккаунт с ролью «Пользователь» или «Суперадминистратор». Кошелёк суперадминистратора является фондом площадки | аккаунт 101 |
| Баланс   | Целое неотрицательное количество мемкоинов                                                                    | 24 мемкоина |

Начальный баланс личного кошелька — 0 мемкоинов.
Фонд получает остатки балансов удалённых аккаунтов и выручку от продажи мемов Площадки.

### Действия

- Пользователь — просмотреть баланс своего кошелька;
- Пользователь — выполнить учётное пополнение своего кошелька;
- Суперадминистратор — просмотреть баланс фонда площадки;
- Суперадминистратор — просмотреть историю операций фонда площадки.

## 8. Операция с мемкоинами

Операция с мемкоинами — запись одного начисления или списания в конкретном кошельке.

### Поля


| Поле              | Описание                                                                                 | Пример                                            |
|-------------------|------------------------------------------------------------------------------------------|---------------------------------------------------|
| Идентификатор     | Уникален                                                                                 | 901                                               |
| Кошелёк           | Кошелёк, в котором изменился баланс                                                      | кошелёк аккаунта 101                              |
| Основание         | Пополнение, покупка, продажа, перечисление остатка в фонд или поступление в фонд         | Продажа                                           |
| Направление       | Начисление или Списание                                                                  | Начисление                                        |
| Сумма             | Положительное целое количество мемкоинов                                                 | 24 мемкоина                                       |
| Сделка            | Указывается для операций по покупке и продаже, включая продажу Площадкой                 | Сделка 801                                        |
| Удалённый аккаунт | Указывается при списании остатка удалённого аккаунта и соответствующем начислении в фонд | Не указан, поскольку операция относится к продаже |
| Дата и время      | Момент выполнения операции                                                               | 2026-11-21T16:32:00+03:00                         |


### Действия

- Пользователь — просмотреть свои операции;
- Пользователь — отфильтровать свою историю по пополнениям, покупкам или продажам.

## 9. Диалог

Диалог — личная переписка двух разных аккаунтов с ролью «Пользователь».

### Поля

| Поле            | Описание                              | Пример      |
|-----------------|---------------------------------------|-------------|
| Идентификатор   | Уникален                              | 1001        |
| Первый участник | Аккаунт с ролью «Пользователь»        | аккаунт 101 |
| Второй участник | Другой аккаунт с ролью «Пользователь» | аккаунт 102 |


### Действия

- Пользователь — начать диалог с другим активным пользователем;
- Участник диалога — открыть существующий диалог;
- Пользователь — просмотреть список своих диалогов.

## 10. Сообщение

Сообщение — текст, отправленный участником личного диалога.

### Поля

| Поле          | Описание                                                           | Пример                    |
|---------------|--------------------------------------------------------------------|---------------------------|
| Идентификатор | Уникален                                                           | 1101                      |
| Диалог        | Переписка, в которую отправлено сообщение                          | диалог 1001               |
| Отправитель   | Один из участников диалога                                         | аккаунт 102               |
| Текст         | От 1 до 2 000 символов после удаления пробельных символов по краям | Привет!                   |
| Дата и время  | Момент отправки сообщения                                          | 2026-11-21T16:32:00+03:00 |

### Действия над сообщением

- Участник диалога — отправить сообщение, если оба аккаунта активны;
- Участник диалога — прочитать сообщение в своей переписке.
